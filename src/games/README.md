# Multi-Game Directory Structure

This folder contains games for the Kolomi educational platform:

- **Game 1**: `Healthy vs Unhealthy` (current primary game in `src/App.jsx` and `src/components/`)
- **Game 2**: `src/games/new-game/` (dedicated space prepared for the next educational game)

To add new assets for Game 2:
1. Place source artwork in `materials/game2/` or `public/assets/game2/`.
2. Implement components inside `src/games/new-game/`.
